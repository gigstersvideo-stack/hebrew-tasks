# Feedback Log — Ивритский тренажёр

Здесь фиксируется РЕЗУЛЬТАТ разбора каждого отзыва с сайта (сами отзывы —
в панели отзывов/Firestore, не тут). Смысл файла: при следующей выгрузке
отзывов не переделывать разбор заново — если отзыв выглядит знакомым,
сверься с этим списком по дате/тексту ПЕРЕД тем, как лезть в код.

Формат: дата отзыва (из экспорта) · текст (сокращённо) · вердикт · пояснение.

Вердикты:
- **УСТАРЕЛ** — отзыв отправлен ДО того, как проблема была исправлена
  отдельным, не связанным с этим разбором коммитом (сверено по дате/времени
  коммита против времени отзыва) — реальных действий не требует, только
  фиксация, что не пропустили.
- **ИСПРАВЛЕН** — исправлено в рамках ЭТОГО разбора, см. версию/коммит.
- **ОТКРЫТ** — подтверждённая, всё ещё актуальная проблема, не исправлена.
- **ДУБЛЬ** — по существу то же, что другой отзыв в этом же списке.
- **ОТЛОЖЕН** — решили не делать сейчас, см. причину.
- **ФИЧА** — предложение новой функции, не баг, статус решения отдельно.

- 2026-09-10 11:48 · «Все еще слышится догз в тренажере на айфон» ·
  **ИСПРАВЛЕН** · это уже ПОСЛЕ коммита «missing-Hebrew-voice notice»
  (v1.18.6, 2026-09-09 09:26) — уведомление не решает саму проблему TTS,
  только объясняет её, значит баг реально не был исправлен. Нашли
  настоящую причину: `hebrewVoice` остаётся `null` (не определено), пока
  `voiceschanged` не долетит, а старый `speak()` в этом случае НЕ блокировал
  воспроизведение — движок сам выбирал голос по `.lang` и иногда молча
  подставлял английский ("догз"). Фикс: живая повторная проверка
  `getVoices()` прямо в момент вызова `speak()` (ловит случай "список уже
  готов, событие ещё не долетело"); если голоса всё равно нет — теперь
  блокируем воспроизведение с отдельным сообщением "голос ещё загружается,
  попробуйте через секунду" (не путаем с "голос не установлен вовсе").
- 2026-09-11 09:48 · «Хочется окошко об окончание дневной нормы и похвалы»

  "🎉 Дневная норма новых карточек выполнена!" в момент, когда дневной лимит

- 2026-09-11 10:16 · «выпадают одни и те же предложения, может быть

  нашли, реальная причина — после дневной нормы старый код выбирал
  СЛЕДУЮЩУЮ карточку чисто случайно из ВСЕХ уже изученных, без учёта того,

  повторялись. Не устраняет повторы полностью (это спейсд-репетишн, повторы
  — часть механики), но делает их менее плотными.
