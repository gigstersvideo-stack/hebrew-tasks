# Ивритский тренажёр

Тренажёр перевода предложений с русского на иврит: 8239 фраз из реальных занятий
(уровни א–ג), с интервальными повторениями (SM-2), очередью ошибок, подсказками
и озвучиванием ответа.

Открыть: `index.html` (весь код и данные — в одном файле, работает без сервера).

Прогресс хранится в localStorage браузера.
