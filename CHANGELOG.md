# Changelog — Ивритский тренажёр

Формат версий: v<крупное>.<новая функция>.<мелкий фикс> — примерно по смыслу,
не строгий semver (тот же принцип, что в CHANGELOG читалки קורא).

## v1.11.0
- Дэшборд перед сессией вместо мгновенного попадания в карточку: сколько
  фраз готово к повтору по каждому уровню и общий итог, кнопка «Начать →»;
  «🏠 Обзор» в панели инструментов возвращает к дэшборду в любой момент.
  Использует только уже отслеживаемые числа (due/освоено по уровням) — без
  выдуманной истории активности, которую нечем было бы честно заполнить.
- Постоянная панель «Слово в фокусе» рядом с карточкой (справа на широком
  экране, под карточкой на узком): корень-эвристика и частое словосочетание
  переехали сюда из общей ленты фидбека, плюс новая кнопка «Разбор от
  ИИ-педагога» — тот же BYOK-Gemini и тот же промпт, что уже работает в
  читалке קורא, разбирает именно слово текущей фразы. Панель пустая, пока
  вы не проверили ответ — иначе корень слова был бы прямой подсказкой.
- Клавиатура вместо мыши: `Enter` уже проверял и переходил дальше, теперь
  `1`–`4` ещё и выставляют конкретную оценку (Снова/Трудно/Хорошо/Легко)
  после проверки, без обязательного клика по кнопкам.

## v1.10.0
- Визуальный редизайн карточки: David Libre вместо системного шрифта для
  иврита (фраза, ввод ответа, подсказка, разбор ответа), акцентная полоска
  сверху карточки, круглая «печать» для уровня (א/ב/...) вместо прямоугольной
  плашки — чтобы не путать с меткой типа упражнения рядом.
- Кнопки оценки (Снова/Трудно/Хорошо/Легко) получили цветовую семантику —
  ту же красно-жёлто-зелёно-бирюзовую лесенку, что и везде в приложении для
  "плохо → отлично", вместо четырёх одинаковых серых кнопок.

## v1.9.1
- Исправлена проверка перевода HE→RU: стилистические пометы в эталонном
  переводе вроде «(высок.)», «(разг.)», «(устар.)» ошибочно требовались как
  часть смысла (например, «Я не против, а (высок.) за» засчитывало «высок»
  как обязательное слово и помечало верный ответ как «Не хватает смысла»).
  Теперь текст в скобках вырезается перед сверкой значимых слов.

## v1.9.0
- Новая панель "Личные карточки" (в статистике) — список всех предложений,
  добавленных из читалки/ИИ-разбора, с кнопкой ✕ убрать каждое. Раньше
  случайно добавленную фразу нельзя было ничем убрать — она просто крутилась
  бы в практике бесконечно.

## v1.8.0
- Личный пул пополняется из читалки: слово, сохранённое при чтении книги,
  добавляет в тренажёр не карточку-слово, а **целое предложение** из книги
  (с готовым переводом), плюс — если для этого слова уже есть подходящее
  предложение в собственном корпусе тренажёра — автоматически подключает и
  его тоже. Личные карточки помечены уровнем "🏷 Личное".
- Технически: новые записи всегда дописываются в конец внутреннего массива
  предложений и никогда не переставляются (в т.ч. удалённые — оставляют
  "заглушку" на своём месте) — иначе у людей, которые уже занимались,
  съехал бы прогресс на уже пройденных фразах.

## v1.7.0
- Иконка сайта (favicon/apple-touch-icon) — узнаваемая вкладка в браузере
  вместо дефолтной, сгенерирована через Cloudflare Workers AI (Flux).
- PWA: `manifest.json` + service worker — сайт можно установить на телефон
  как приложение, оболочка страницы кешируется и открывается офлайн.
- Firestore теперь пишет через persistent local cache — если соединение
  пропадает, изменения не теряются, а тихо ждут восстановления сети и
  досинхронизируются сами.
- Индикатор синхронизации стал постоянным, а не разовым сообщением:
  показывает "☁ Синхронизировано" или "📴 Офлайн" в реальном времени,
  реагируя на события online/offline браузера.

## v1.6.2
- Вход через Google переведён с `signInWithRedirect` на `signInWithPopup`:
  редирект терял состояние входа на переходе между тремя доменами
  (accounts.google.com → домен Firebase → github.io) — судя по всему,
  из-за расширений-блокировщиков в браузере. С попапом вход либо
  срабатывает, либо явно и понятно падает с кодом ошибки.

## v1.6.1
- Ошибки входа и синхронизации через Firebase больше не проглатываются
  тихо (`.catch(() => {})`) — теперь видны в консоли и в статусе под
  кнопкой входа. Без этого «ничего не произошло при клике» было
  неотличимо от настоящей ошибки.

## v1.6.0
- Необязательный вход через Google (проект Firebase `ivrit-progress`,
  общий с читалкой קורא — один аккаунт на оба сайта). Синхронизирует между
  устройствами прогресс FSRS по каждой карточке, журнал ошибок, серию дней
  и личный пул предложений. При входе сливается с тем, что уже накопилось
  локально как у гостя (по каждой карточке побеждает более свежая попытка,
  счётчики ошибок складываются) — без входа всё работает как раньше,
  только локально.
- Личный пул предложений: чекбоксы по уровням в панели статистики — какие
  уровни вообще участвуют в практике — плюс кнопка «Убрать эту фразу из
  пула» на самой карточке. По умолчанию — все 8239 фраз.

## v1.5.1
- Ссылка на читалку קורא (hebrew-reader) в шапке — и обратная ссылка на
  тренажёр со стороны читалки.

## v1.5.0
- Планировщик повторений переведён с SM-2 на **FSRS-6** — тот же алгоритм,
  что использует современный Anki. Точный порт опубликованных формул
  (github.com/open-spaced-repetition/ts-fsrs) со стандартными
  (необученными) весами, поверх — короткие обучающие шаги (как в Anki)
  перед выходом на длинные интервалы. Сверено с независимой Python-копией
  тех же формул — совпадение до 6 знака на 8 сценариях.
- Старый прогресс SM-2 (несовместимый формат) сбрасывается только в части
  расписания повторений — журнал ошибок, серия и настройки сохраняются.

## v1.4.0
- Подбор новых (ещё не изучавшихся) фраз теперь по принципу «i+1»: среди
  кандидатов предпочитаются те, где незнакомо меньше всего слов — а не
  случайные.
- Аудирование новой фразы сначала звучит медленнее (0.75×), обычная
  скорость — после того как фраза освоена на слух.
- После проверки может показаться часто встречающееся словосочетание с
  этим словом (намайнено по всему корпусу — 1129 пар, встречающихся в 5+
  предложениях).

## v1.3.1
- Добавлен `<meta name="viewport">` и полноценный HTML-документ для
  версии на GitHub Pages (артефакт Claude оборачивается платформой

## v1.3.0
- Явная самооценка (Снова / Трудно / Хорошо / Легко) в дополнение к
  автоматической — идёт напрямую в SM-2.
- Журнал слов, в которых чаще всего ошибаетесь (по всей истории, не по
  одной фразе).
- Счётчик дней подряд практики.
- Шаг «блокированной» практики: новая или только что забытая карточка
  обязательно повторяется ещё раз в течение ~10 минут, прежде чем уйти в
  долгосрочное расписание; потолок интервала повторения — 180 дней.

## v1.2.0
- Четвёртый тип задания — пропуск слова (cloze): в знакомом предложении
  скрыто одно слово, подсказка — контекст и русский перевод. Легче
  полного перевода, тренирует конкретные словоформы.
- После проверки — слова с похожим «скелетом корня» из других фраз
  (эвристика по общим буквам после снятия огласовок/финальных
  букв/самых однозначных приставок и окончаний — не точный морфологический
  разбор).

## v1.1.0
- Второй и третий тип задания: перевод HE → RU (проверка по смыслу —
  ключевые слова, порядок не важен) и аудирование (проигрывание фразы,
  печать услышанного на иврите).
- Гибкая проверка иврита: финальные/обычные буквы, написание מלא/חסר
  (יי/י, וו/ו), опечатка в одну букву, небольшой список синонимов — не
  считаются ошибкой, такие места подчёркнуты пунктиром.

## v1.0.0

  простым SM-2, посимвольный/пословный разбор ошибок.
